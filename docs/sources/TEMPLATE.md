# <Source name>

> **Verdict:** Go / Go with permission / Parked / Not onboarded. **Effort:** S / M / L.
> **Researched:** YYYY-MM-DD. Unconfirmed details are marked UNVERIFIED.

One paragraph: what this source is, what it would give Prepora, and the deciding facts.

## 1. Legitimacy

- **Publisher:** who, and on whose behalf.
- **Terms / copyright / licence:** quote the lines that matter, with URLs.
- **robots.txt:** the lines that matter.
- **Question text and the site's own work:** whose is each.
- **Bot walls or forms:** note them. Prepora never bypasses them, and never submits personal data
  to get content.
- **Permission needed?** → an entry in [permissions.md](permissions.md).

## 2. Exam landscape → knowledge index

- The natural hierarchy.
- A mapping table with two or three real examples: exam, hierarchy template and levels, paper,
  edition (language/series), sections.
- Gaps the model can't represent yet.

## 3. How it publishes

Listing pages, URL patterns, formats, years reachable, volume, host changes. Include one checked
sample: its `pdfinfo` creator, and whether its text is usable.

## 4. Question shape

Types, media and equations, sections, marks, negative marking, languages, booklet series.

## 5. Answers

Which rungs of the answer ladder exist, how keys match the paper, and how dropped questions,
"marks to all" and provisional or final keys are shown.
