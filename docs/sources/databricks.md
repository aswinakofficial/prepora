# Databricks certifications

> **Verdict:** Go, a small set. **Effort:** S.
> **Researched:** 2026-10-01. Unconfirmed details are marked UNVERIFIED.

Every Databricks exam guide PDF ends with a "Sample Questions" section: 5 questions with answer
letters and no explanations. The guide notes "These questions are retired from a previous version
of the exam." Guides are re-issued whenever an exam changes, and the date in each URL gives a
natural version. Weighted sections give the topic structure.

## 1. Legitimacy

- **robots.txt:** `Allow: /`.
- **Licence:** no licence notice seen in the guide. See [permissions](permissions.md).

## 2. Exam landscape → knowledge index

- **The hierarchy:** Databricks → level (Associate / Professional) → exam (Data Engineer Associate)
  → guide version ("2026-05", "exam version as of May 4, 2026").
- **Knowledge index:** organization `databricks`, exam `databricks-data-engineer-associate`,
  template `version`.
- **Subjects:** the guide sections with weights, e.g. "Section 5: Implementing CI/CD (10%)", become
  subjects with `weightPct`.
