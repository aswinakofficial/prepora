# Question 1

The time complexity of the best sorting algorithm in the worst case is:

- A. O(n)
- B. O(n log n)
- C. O(n²)
- D. O(log n)

**Answer:** B

**Explanation:**

The best possible time complexity for a comparison-based sorting algorithm is
O(n log n) in the worst case. This is the lower bound proved by information theory
(decision tree argument). Algorithms like Merge Sort and Heap Sort achieve this.

# Question 2

Which data structure is used in BFS traversal of a graph?

- A. Stack
- B. Queue
- C. Priority Queue
- D. Deque

**Answer:** B

**Explanation:**

BFS (Breadth-First Search) uses a Queue to explore nodes level by level.
A node is enqueued when discovered and dequeued when visited, maintaining FIFO order.

# Question 3

The number of binary trees with 3 nodes is:

- A. 4
- B. 5
- C. 6
- D. 8

**Answer:** B

**Explanation:**

Using the Catalan number formula Cₙ = (2n)! / ((n+1)! × n!),
for n=3: C₃ = 6!/(4! × 3!) = 720/144 = 5.
There are 5 distinct binary tree structures with 3 nodes.

**Topic:** Trees and Binary Trees
