# content/

Place Prepora Markdown content files here.

## Directory structure

```
content/
├── exams/              # Exam-specific content
│   ├── kerala-psc/
│   └── gate/
└── question-sets/      # Question set Markdown files
    ├── kpsc-ae-2025-civil.md
    └── gate-cs-2024.md
```

See `agents/content/schema.md` for the Prepora Markdown format.

Run `pnpm content:validate` before `pnpm content:import`.
